Log Analyzer

Կուրսային աշխատանք «Ծրագրավորման տեխնոլոգիաներ» · թեմա №28 · C++17

Ծրագիրը կարդում է log ֆայլը տող առ տող։ Յուրաքանչյուր տողից առանձնացնում է ժամանակը, մակարդակը (ERROR / WARNING / INFO / DEBUG) և հաղորդագրությունը։ Հետո ֆիլտրում է տողերը, հաշվում վիճակագրություն և պատրաստում հաշվետվություն text, CSV կամ HTML տեսքով։

Ինչպես է աշխատում

Ամեն տող անցնում է նույն հերթականությամբ (pipeline)․

  1. Parser-ը regex-ով բաժանում է տողը ժամանակի, մակարդակի և հաղորդագրության։ Եթե տողը ձևաչափին չի համապատասխանում, այն բաց է թողնվում։
  2. Filter-ը որոշում է՝ տողը պահե՞լ, թե՝ ոչ։ Բոլոր ֆիլտրերը միավորված են մեկ AndFilter-ում։
  3. Հաշվիչները ստանում են ամեն ընդունված տողը և հաշվում վիճակագրություն՝ ըստ մակարդակի, ըստ ժամի և ամենահաճախ հանդիպող հաղորդագրությունները։
  4. Reporter-ը գրում է հաշվետվությունը ընտրված ձևաչափով։

Փորձիր

Ընտրիր ֆիլտր և տես, թե samples/sample.log-ից որ տողերն են մնում.

Աշխատացնելու օրինակներ

Բոլոր օրինակները աշխատեցվում են նախագծի թղթապանակից՝ build-ից հետո։

Ինչ ենք ուզումՀրաման
Ամբողջ ֆայլը և վիճակագրությունըlog_analyzer.exe samples\sample.log
Միայն սխալներըlog_analyzer.exe samples\sample.log --level ERROR
Սխալներ և զգուշացումներlog_analyzer.exe samples\sample.log --level ERROR,WARN
Բառով որոնումlog_analyzer.exe samples\sample.log --grep connection
Regex-ով որոնումlog_analyzer.exe samples\sample.log --grep "slow query: [0-9]{4}"
Հանել անհետաքրքիր տողերըlog_analyzer.exe samples\sample.log --exclude "heartbeat|logged in"
Ժամանակի միջակայքlog_analyzer.exe samples\sample.log --from "2026-11-17 10:00:00" --to "2026-11-17 11:00:00"
Համակցված ֆիլտրlog_analyzer.exe samples\sample.log --level ERROR --grep connection --from "2026-11-17 10:30:00"
CSV ֆայլ (Excel-ի համար)log_analyzer.exe samples\sample.log --level ERROR --report csv --out errors.csv
HTML հաշվետվությունlog_analyzer.exe samples\sample.log --report html --out report.html
Այլ ձևաչափի log ([ժամ] LEVEL: msg)log_analyzer.exe other.log --format bracket
Օգնությունlog_analyzer.exe --help

Ֆայլերի կառուցվածք

src/Parser.*Տողի parse, ձևաչափերի factory

src/Stats.*Վիճակագրություն
src/Analyzer.*Pipeline-ը միացնող դաս
src/Reporter.*Text / CSV / HTML հաշվետվություն
